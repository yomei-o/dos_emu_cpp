C and C++ compiled and linked by Watcom C/C++ 11.0c, in your browser

dos_emu_cpp is an 8086/80386 MS-DOS emulator in C++/WebAssembly, with a built-in DPMI host so DOS-extended programs run. Below, the real Watcom compiler and linker turn the source in the editor into a DOS .EXE — and then the emulator runs that. Compiler, linker and program are all guest code; nothing leaves your browser.

Source — pick a language, edit freely

the file name decides which compiler runs: wcc or wpp
the toolchain is fetched only when you ask for it

Three DOS programs deep, and each one leans on a different part of the emulator. wcc and wpp are stubbed for FlashTek X-32 and hand themselves to w32run.exe, which is not a DPMI client at all: it loads its own IDT, runs the application at ring 3 and reflects DOS calls itself. wlink is a DOS/4GW program, which is a client of the built-in DPMI host and passes its DOS calls back down through INT 31h 0302h. What they build is plain 16-bit real mode. If you would rather watch one command do all of it, wcl hello.c works too.
