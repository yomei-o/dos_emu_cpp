A DOS prompt that compiles C with LSI C-86

dos_emu_cpp is a 16-bit MS-DOS emulator in C++/WebAssembly. Below is the real FreeDOS COMMAND.COM running inside it. Type a command and it dispatches it like DOS — e.g. run the 1993 LSI C-86 compiler on the C in the editor, then run the .EXE it produces. Nothing leaves your browser.

A:\PROG.C (edited live; saved before each command)

Try: dir  ·  lcc prog.c  ·  dir  ·  prog  ·  ver  ·  type prog.c

FreeDOS prompt

A:\>
loading the emulator, COMMAND.COM and the compiler…
Each line runs as COMMAND.COM /C <command> — a real FreeCOM dispatch. FreeCOM's internal commands (dir, type, ver, echo, …) and external programs (the compiler and the .EXE it builds, run as nested DOS programs) both work. See the README.

This page is the 16-bit side. There is also a 32-bit one, where DJGPP's gcc and g++ compile C and C++ to protected-mode executables through the emulator's built-in DPMI host.
