Compile & run C with LSI C-86 — in your browser

dos_emu_cpp is a 16-bit MS-DOS emulator in C++/WebAssembly. This page runs the real LSI C-86 3.30 (a 1993 DOS C compiler) inside it: it compiles the C below — the driver spawns its passes CPP→CF→CG86→R86→LLD as DOS programs — into a DOS .EXE, then runs that .EXE. Nothing leaves your browser.
