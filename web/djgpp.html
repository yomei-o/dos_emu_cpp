32-bit C and C++ compiled by DJGPP gcc/g++, in your browser

dos_emu_cpp is an 8086/80386 MS-DOS emulator in C++/WebAssembly, with a built-in DPMI host so DOS-extended programs run. Below, the real DJGPP gcc 3.4.6 compiles the source in the editor to a 32-bit protected-mode .EXE — and then the emulator runs that. Compiler, assembler, linker and the program are all guest code; nothing leaves your browser.

the file name decides which compiler runs: cc1 or cc1plus
the toolchain is fetched only when you ask for it

The four passes are driven from this page rather than by the gcc driver: cc1 → as → ld → stubify. gcc 3.4.6's own driver cannot exec cc1 out of libexec/ under this emulator, and the 4.7.4 build whose driver does work is three times the size and takes about a minute per file. Running the passes here is quicker, and each stage leaves a real artefact you can look at.
